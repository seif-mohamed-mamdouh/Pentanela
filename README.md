# Pentanela Website v2

Premium static corporate website for Pentanela.

## Preview locally

Open `index.html` directly, use VS Code Live Server, or run:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Before publishing

Replace:

- `info@pentanela.com` with the real company email if different.
- `+20 XXX XXX XXXX` with the real phone number.
- `[Replace with date]` in Privacy Policy and Terms & Conditions.

## Hosting

This is a static website and can be hosted on Vercel, Netlify, GitHub Pages, Cloudflare Pages, or any normal web hosting service.
